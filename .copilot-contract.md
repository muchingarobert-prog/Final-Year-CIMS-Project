\# CIMS PROJECT — COPILOT CONTRACT (NON-NEGOTIABLE)



This project follows the README.md exactly. Copilot MUST treat README.md as the

single source of truth. Any instruction that contradicts README.md is invalid.



\## Absolute Rules

1\. Read README.md and .copilot-contract.md before every task.

2\. Do not invent API endpoints. Only use endpoints listed in README.md

&#x20;  ("API Endpoints" section) and the authoritative show\_urls\_output.txt file.

3\. Do not rename Django apps, models, or URL prefixes.

4\. Do not modify backend code unless explicitly told.

5\. Do not touch dist/ or node\_modules/.

6\. Frontend work happens ONLY inside frontend/src/ plus frontend/package.json,

&#x20;  frontend/vite.config.js, frontend/index.html, frontend/.env\*.

7\. Never call axios or fetch directly in a React component.

&#x20;  All HTTP goes through frontend/src/api/client.js.

8\. Never hardcode API URLs.

9\. Never read localStorage inside a page/component. Use useAuth().

10\. Every data-fetching page handles: loading, error, empty, success.

11\. Every mutation shows pending state and error feedback.

12\. Use shared components for Button, Input, Select, Textarea, Card, Badge,

&#x20;   Spinner, Alert, Modal, Table, SectionCard, DataTable, ConfirmDialog,

&#x20;   Breadcrumbs, Tabs, StatGrid.

13\. Functional components + hooks only. No class components.

14\. After every file, output a short summary: "Created X. Run Y to verify."

15\. If unsure, STOP and ask. Do not guess.
